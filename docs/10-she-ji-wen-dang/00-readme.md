## 关键约束（设计时不得违反）

- **甲方渠道：甲方现在渠道，不用自己加。** 第三方系统只接甲方已有渠道
  （大麦渠道、微信支付、北京银行等），不得自行新增渠道。见 `07-...` 现状对照与 skill。
- **AI + 规则混合模式：** 关键业务流程（支付、库存、核销）由确定性系统保障，
  AI 只承担辅助与增强角色。AI 能力上线前必须标注为模拟（模拟支付、规则客服（模拟）· 未接入大模型）。
- **不编造数据：** 资源名、价格、需求、数字只来自小组文件或 Lam 批准的草稿；来源没有的字段留空。
- **模拟能力必须标注：** 支付、AI、区块链、VR、渠道同步是模拟，不得写成真实/已上线。
- **技术选型未定事项不写成已定：** AI 中台的智能体路由层语言（Python 服务还是 Node 层）、
  DeepSeek API 接入时点、私有部署时点，均是第二/三阶段决策，现在只记录方向，不写成结论。
