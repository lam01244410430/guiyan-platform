## 设计语言

- **主题：** 夜间剧场——深松绿 `#0B3D36`、朱砂红 `#C8452C`、金 `#C9A24B`、暖纸 `#F7F4EE`；
  展示字体 Noto Serif SC，正文字体 Be Vietnam Pro + Noto Sans SC。禁用 Inter、禁用紫蓝渐变、
  禁用三张等宽卡片（改用一张宽主卡 + 紧凑卡）。
- **头部（64px，吸顶）：** logo 最左，导航 + 语言 + 微信 + 我的票 + 认证区最右；
  登录后只显示一个 pill："Hi + 名字"（头像圆 + 名字 + chevron），点开下拉菜单：
  我的账户 / 分隔线 / 我的订单 / 分隔线 / 退出登录（红色在底）。
- **语言：** 下拉选择，仅中文 / Tiếng Việt / English 三种；默认中文；切换整页重渲染，
  订单与收藏保留。i18n 185 键/语言。
- **响应式：** ≤1100px 藏品牌标语、微信变图标；≤860px 导航收进汉堡菜单；
  ≤560px 藏微信按钮、"我的票"只留图标+数字。头部任何宽度都不换行、不溢出。
- **管理站：** 完全独立的 web（`/admin/`），松绿侧栏 240px、纸背景、宽主收入卡 + 4 紧凑统计；
  5 个只读视图：总览 / 订单 / 用户 / 资源 / 需求。高级管理面板是阶段 5。
- **悬浮 AI 聊天（2026-11-11，Lam 的要求）：** 客户站右下角一个圆形悬浮按钮（56px，
  `position: fixed`，滚动时始终可见），点开上面弹出聊天面板；首页与用户页共用同一组件。
  后端是 Lam 的试用聊天服务（`34.96.190.102`，LangGraph + DeepSeek，`POST /api/chat`，
  `{message}` → `{reply}`，2026-11-11 实测 3.6 秒有回复）。本站是 HTTPS，试用服务是 HTTP，
  浏览器会拦截 HTTPS 页面直接调 HTTP（mixed content），所以前端不直调 IP，而是走本站同源代理
  `POST /api/assistant/chat`（环境变量 `AI_CHAT_URL`，默认即该 IP 的 `/api/chat`）；代理超时或失败
  时 fail-open，回落到现有规则客服 `GET /api/assistant?q=`，用户仍能得到回答。
  诚实标注：面板注明试用版。**2026-11-11 已接通桂演实时目录：** 试用后端新增价格工具
  `tra_cuu_gia_ve`（查公开 `GET /api/resources`，60 秒缓存，演出类优先），实测问刘三姐票价答
  **¥280/张**（另区分 IP 授权 ¥8000/次）；原先写死的“15 张普通票、VIP 售罄”已改为查实时库存。
  知识库也已换成桂演真实规则（退票/改签/预订/入场/非遗/热门，6 主题 × 中越英 3 语言，共 18 条；
  旧样本“提前 24 小时才能退票”与桂演规则冲突，已删除）。
  **语言跟随（2026-11-11 升级）：** 聊天回答跟随本站当前语言（中文/越南语/英语切换时，回答也切换）。
  试用后端现已接受 `language` 字段（`zh|vi|en`，缺省为中文），每次请求按该语言生成 system prompt
  强制回答语言；本站代理转发 `{message, language}`，同时保留消息前加一句目标语言的简短指令
  （如“请用中文回答以下问题：”）作为双重保障。回落到规则客服时客户端用现有 i18n 答案键按当前
  语言渲染，不直接显示服务端中文文本。
  问候语在对话为空时随语言切换重新渲染，已发送的消息保持原语言不变。
  页内原有规则客服区块保留不动，悬浮窗是新增的。
